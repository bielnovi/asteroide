# Asteroids

Jogo educativo feito com Phaser 3.

## Como jogar

- Escolha um dos três mapas no menu principal.
- Escolha teclado ou mouse em **Opções de controle**.
- No teclado, use as setas para pilotar e espaço para atirar.
- Com o mouse, mova o cursor para pilotar e clique para atirar.

O jogo é publicado automaticamente no GitHub Pages a cada atualização da branch `main`.
